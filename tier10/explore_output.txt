   t   shot ok   16 shots ok   (needs 2^t > 2 order = 82, so t >= 7)
    4     7.5%        14.7%

    9    94.0%       100.0%
   t = 7 (2^t > 2q) is the size where rounding y*q/2^t is guaranteed to return s for the
   closest peaks. Smaller t blurs s, but voting over many shots still works down to t = 5;
   t = 4 is too coarse. Fewer phase bits means fewer rounds, so fewer gates.

3. Shor discrete log, textbook version (two counting registers of 7 qubits at once, 23 qubits)
   Built and measured, not simulated by default: 23 qubits means a 2^23-amplitude statevector
   and ~37 000 gates (set TIER10_SIMULATE_TEXTBOOK=1 to run it, many minutes).
   Same multipliers and same result as the recycled version: U_g and U_A commute, so the two
   phase estimations give the same pair (s, s*a) whether run in parallel or one after the other.

   Marked items: x and x + 41 when both fit in 6 bits (g^x = A has 1 or 2 solutions in 0..63).
   One noiseless simulation, probability recorded after every round (438 s).
   Chance that a shot gives x with x mod 41 = a, against rounds (theory with 2 marked items):
   rounds = 0:   3.1%   theory   3.1%
   rounds = 1:  25.8%   theory  25.8%

   rounds = 5:  86.0%   theory  86.0%
   Best at 4 rounds, about (pi/4) sqrt(64/2) = 4.4. More rounds overshoot.
   Rounds needed at 6 qubits: 4. Brute force over 41 values needs up to 41 checks, so even at
   this size Grover's oracle (full modular exponentiation, twice per round) costs more than
   brute force itself: speed-up only shows once the search space is huge.

   Shor columns are simulated (13157 CX). The Grover column is an ESTIMATE, not a simulation:
   a run with no CX error at all (probability (1 - p)^49698) succeeds as ideal, any error is
   treated as a random guess (1/41). Simulating the noisy Grover circuit is too slow here.
   Random guessing gets the right vote 1/41 = 2.4% of the time. Today's hardware is around
   p = 0.001. Error mitigation (zero-noise extrapolation, error cancellation) cannot rescue
   circuits this deep; error correction is needed.
